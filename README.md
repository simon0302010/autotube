# autotube

If you didn't hear me properly, I said:

Autotube will become a software that lets and AI agent create and upload explanatory YouTube videos.  
Please note that we are just starting development and got a long way to go.

This isn't a note taking app, as quite a bit of people were confused regarding that somehow.

Features so far:

- A basic TUI
- AI requests working
- Tools implemented
- A config system
- HORRIBLE compaction
- Notifications

The agent has access to these tools so far:

- wikipediaSearch: search wikipedia for articles
- fetchWikipediaArticle: fetch a wikipedia article's text and available images
- downloadWikipediaImage: download a specific image off of wikipedia

- readFile: read files.... 🥺🥺🥺🥺🥺🚀🚀✨✨✨

- webFetch: fetch a url's content via exa proxy
- webSearch: search the web via exa proxy

All made by yours truly, kablow

Our current long-term plan is to implement video-editing tools so the agent can directly edit the video according and to implement direct uploads to youtube via the API
